No. This repo was not designed as “run Main first, then Batch.”

AFI_Rickettsiales_Batch.wdl is just a wrapper around AFI_Rickettsiales_Main.wdl: it takes `samples`, then scatters and calls `AFI_Rickettsiales_Main` once per sample. So the intended choice is:

1. Use `AFI_Rickettsiales_Main` for one sample at a time, or for debugging.
2. Use `AFI_Rickettsiales_Batch` for a real sequencing run with multiple samples and shared run-level inputs.

The one place this repo is step-wise is different: the README describes a two-pass NTC workflow, not a Main-then-Batch workflow. The pattern is in README.md: first run a batch for one sequencing run including NTC controls, then build `ntc_background.tsv` from the NTC metrics, then rerun that same run with the generated background file. So the step-wise logic is “first pass to derive NTC background, second pass for final interpretation,” not “Main before Batch.”

On your Main screen, the truly relevant fields are the top-level ones from AFI_Rickettsiales_Main.wdl:
- required: `sample_id`, `r1_fastq`, `r2_fastq`, `rickettsiales_panel`, `ntc_background`
